This folder stores official admission PDF documents.

Place PDF files from the Maharashtra CET Cell website here:
https://cetcell.mahacet.org/

Files in this folder are automatically indexed when the server starts.
You can also upload files through the web interface.

IMPORTANT:
- Do not store private student documents here.
- Always verify document content against the official CET Cell website.
- This folder is excluded from git commits (.gitignore).
